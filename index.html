About Puja Universe

PUJA is an effectively unbounded, virtualized profile architecture. It renders an infinite sequence of unique human profiles while keeping memory and DOM footprints strictly bounded.

  • Deterministic Generation: Every profile is derived on-demand from its BigInt ID using robust hashing. Revisiting any profile ID reconstructs the exact same identity.
  • True Virtualization: Only a small pool of DOM nodes is maintained and recycled as you scroll across quadrillions of profiles.
  • BigInt Precision: Operates seamlessly beyond JavaScript's safe integer limit (`Number.MAX_SAFE_INTEGER`).
